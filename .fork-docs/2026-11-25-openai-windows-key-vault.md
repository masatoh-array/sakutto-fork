# OpenAI APIキーの保持と翻訳エラー（Windows版Chrome）

## 初回セットアップ

対象はこのフォークの Windows 版 Chrome です。補助プログラムはソースからローカルでビルドし、管理者権限を使わず現在のWindowsユーザーに登録します。Sakuttoのローカル翻訳やCopilotを使うだけなら不要です。

1. 既に拡張機能を読み込んでいる場合は、同じディレクトリの中身を新しいビルドで更新し、`chrome://extensions` で再読み込みします。既存の拡張を削除・再登録すると、保存済みの設定やキャッシュを引き継げない場合があります。
2. `chrome://extensions` の「デベロッパー モード」をオンにし、Sakuttoの32文字の拡張機能IDを控えます。
3. このフォルダー配下の `windows-openai-vault/install.ps1` と `Vault.cs` を同じフォルダーに置きます。内容を確認し、Windows PowerShellで次を実行します。IDはAPIキーではありません。Windowsの標準 .NET Framework 4.x のC#コンパイラを使います。
   ```powershell
   .\windows-openai-vault\install.ps1 -ExtensionId '<Sakuttoの拡張機能ID>'
   ```
4. Sakuttoの設定でOpenAI APIキーを入力し、「送信・課金を理解してOpenAIを有効化」を押して、OpenAI接続と補助プログラム利用の権限を承認します。キーの入力は設定画面だけで行います。旧版のメモリにしかなかったキーは新バージョンに引き継げません。控えがなければ新しいキーが必要です。
5. 正常に保存されたら、Chromeを完全終了して再起動し、設定で「保存済み」が表示されること、翻訳に成功することを確認します。

Windows用スクリプトは実行ポリシーを変更しません。組織のPCで実行がブロックされる場合は管理者に確認してください。同じWindowsユーザーのChromeでは、最後に登録したIDのSakuttoだけがこの補助プログラムを起動できます。拡張のIDを変更した場合は新しいIDで再登録が必要です。

## 安全性と変更範囲

- キーはWindowsのユーザー単位のDPAPIで暗号化し、ローカルの `%LOCALAPPDATA%\Sakutto\OpenAI\<拡張ID>` に保存します。Chromeの永続ストレージに入るのはランダムな保管先IDと変更識別子のみです。キーを他の端末へ同期しません。
- 補助プログラムはChromeのNative Messagingでのみ接続し、待ち受けポートや外部接続を持ちません。翻訳時のキーは拡張のバックグラウンドから固定のOpenAI APIへ渡し、ページやコンテンツスクリプトに返しません。これは閲覧ページや平文ファイルへの露出を避ける仕組みです。同じWindowsユーザー権限で動くマルウェアまでは防げません。
- 利用をやめる場合は、拡張機能を削除する**前に**設定で「キーを削除」を選びます。拡張のアンインストールだけではWindows側の暗号化済みファイルは消えません。
- OpenAI失敗時は、事前に定義した分類と対処だけを表示します。キーやAPIレスポンスの生のメッセージを表示・記録したり、他の翻訳方式へ自動で切り替えたりしません。
- PLaMo、Chrome内蔵翻訳、Microsoft 365 Copilotの認証方式は変更対象外です。Sign in with ChatGPTは調査のみで、この変更には含みません。

## 再開時の確認

- Windowsで実物の補助プログラムを登録し、初回保存、ブラウザ完全終了、翻訳、キーの置き換え、削除を確認する。OpenAIの有効な実キーをコードやログに入れない。
- 同じページでも本文・周辺文脈・用語集・モデル・言語・バッチの並びが変わるとキャッシュはミスする。追試する場合は固定ページと同じ翻訳条件を使い、再訪時のAPI呼び出し回数を数える。OpenAIキャッシュは前回の実装を維持し、保存済みのキーを読み出せる場合に利用する（ヒット時はOpenAIへ接続せず、キーの有効性をAPIに問い合わせない）。

今回の検証：型チェック、Lint、関連テスト153件、拡張のZIPビルドと内容監査が成功。模擬APIによるページ翻訳の確認では、初回2回、同じページの再訪0回、1ブロック変更時1回、同じテキストでも別オリジンでは2回。これはブラウザとAPIを模擬した検証で、実Windowsでの補助プログラム実行・再起動と実APIでの翻訳は未検証。全体テストの既知の3件（ベンチ履歴、リリース文面、同梱のWllama JSを拾うネットワーク検査）は変更対象外。
